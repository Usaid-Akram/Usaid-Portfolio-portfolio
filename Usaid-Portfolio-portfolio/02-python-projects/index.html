Simple Calculator

Uses input, numbers, operators and conditional statements to perform basic calculations.

num2 = float(input("Second number: "))
print("Sum:", num1 + num2)
print("Product:", num1 * num2)
🎯

Number Guessing Game

Uses a random number, a loop and conditions to let a player guess the answer.

import random
secret = random.randint(1, 10)
guess = int(input("Guess 1-10: "))
if guess == secret:
    print("You got it!")
else:
    print("The number was", secret)
📝

Mini Quiz

Uses questions, user input and a score variable to create a short quiz.

score = 0
answer = input("What does HTML stand for? ")
if answer.lower() == "hypertext markup language":
    score += 1
print("Your score:", score)
🌡️

Temperature Converter

Uses a formula and numeric input to convert Celsius into Fahrenheit.

celsius = float(input("Celsius: "))
fahrenheit = (celsius * 9/5) + 32
print("Fahrenheit:", fahrenheit)
